# 3D & VFX Pipeline Automation Toolkit

## Overview
This repository contains a collection of open-source Python scripts designed to automate repetitive tasks in 3D rendering and VFX pipelines. The goal is to bridge the gap between technical logic and creative workflows, allowing freelance artists to speed up their scene preparation and rendering processes.

## Current Features
* **Auto Scene Setup (`auto_scene_setup.py`)**: A Blender Python script that automatically configures a scene with standard 3-point lighting, optimizes render settings for Cycles, and creates a default camera rig.

## Planned Features
* AI-assisted node generation for automated material setups.
* Batch rendering control scripts.
* API integrations for background render queue management.

## Installation
1. Download the scripts from this repository.
2. For Blender scripts, open Blender, navigate to the Scripting workspace, and open the `.py` file.
3. Run the script to apply the automated setups to your current scene.
